1. Elige el dado del edificio

Edificios

El número del dado elige el edificio. «Toca» quiere decir casilla de al lado: arriba, abajo, izquierda o derecha.

    Cómo se juega

    1. Cada turno salen tres dados. Elige uno para el edificio: su número dice cuál.
    2. Elige otro para el lugar: puedes construir en cualquier casilla libre de esa fila o de esa columna.
    3. El tercer dado se descarta. Si ninguna combinación cabe, pones una ruina donde quieras.
    4. Cuando las 36 casillas están llenas, se cuentan los puntos de cada edificio.
