# Villa de dados

Juego de dados original para un jugador. Cada turno tiras tres dados: uno elige el edificio (casa, campo, fuente, taller, mercado o iglesia) y otro la fila o columna donde lo construyes. Cuando el pueblo de 6×6 se llena, cada edificio puntúa según sus vecinos. Reto del día con los mismos dados para todo el mundo y partida libre.

🔗 **Jugar ahora:** https://adrianezd.github.io/villa-de-dados/

Sitio estático sin dependencias ni build (HTML, CSS y JavaScript vanilla) servido por GitHub Pages. Funciona sin conexión gracias a `sw.js`. Los récords se guardan solo en tu navegador (`localStorage`).
